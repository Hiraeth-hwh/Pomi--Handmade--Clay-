Pomi – Handmade Clay E-commerce Website
Pomi is a handmade clay products e-commerce website built with Django. It provides a simple and user-friendly shopping experience for customers who love cute and creative handmade products.
Features
User Registration and Login
Browse Handmade Clay Products
Newest Products and Sales Items
Product Details
Add to Cart
Update and Delete Cart Items
Wishlist
Contact Page
Payment Functionality

Installation and Setup
Clone the repository:
git clone https://github.com/Hiraeth-hwh/Pomi--Handmade--Clay-.git

Navigate to the project folder:
cd ecommerce_project

Install Django:
pip install django

Run database migrations:
python manage.py migrate

Start the development server:
python manage.py runserver

Open your browser and visit:
http://127.0.0.1:8000/
