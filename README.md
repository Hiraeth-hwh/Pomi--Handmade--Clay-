Installation and Setup
Clone the repository:
git clone https://github.com/Hiraeth-hwh/Pomi--Handmade--Clay-.git

Navigate to the project folder:
cd ecommerce_project

Install Django:
pip install django

Run database migrations:
python manage.py migrate

Start the development server:
python manage.py runserver

Open your browser and visit:
http://127.0.0.1:8000/

Installation Guide
1. Download the Project
Download the ZIP file from this GitHub repository and extract it.
2. Open the Project Folder
Open the extracted project folder in VS Code.
3. Create a Virtual Environment
python3 -m venv venv
4. Activate the Virtual Environment
source venv/bin/activate
5. Install Required Packages
pip install -r requirements.txt
6. Apply Database Migrations
python3 manage.py migrate
7. Load Sample Product Data
python3 manage.py loaddata store/fixtures/products.json
8. Run the Development Server
python3 manage.py runserver
Open the following URL in your browser:
http://127.0.0.1:8000/index/
Project Structure
• store/ – Product, category, and store functionality
• cart/ – Shopping cart functionality
• payment/ – Payment functionality
• templates/ – HTML templates
• static/ – CSS, JavaScript, and static files
• media/product_images/ – Product images
• store/fixtures/ – Sample product data
• requirements.txt – Required Python packages
